# FC SBC Auto

Юзерскрипт для EA FC Web App: читает ваш клуб, подбирает самый «дешёвый» по ценности состав под
требования SBC, расставляет игроков и (по желанию) отправляет челлендж.

## Установка
1. Поставьте Tampermonkey в Chrome.
2. `npm run build`, затем откройте `dist/fc-sbc-auto.user.js` в Tampermonkey (создать скрипт → вставить).
3. Откройте Web App → любой SBC → экран состава. Справа внизу появится кнопка «⚡ Авто-сборка».

## Настройки (localStorage `fcsbc.cfg`, JSON)
`protectRating` (86), `protectSpecial` (true), `maxRepeats` (1), `submit` (true), `delayMin/delayMax` (мс).
Для пробы поставьте `submit: false` — скрипт только заполнит состав.

## Как выбираются карточки
Ценность карточки растёт экспоненциально с рейтингом; ×1.5 за редкую, ×6 за особую; ×0.35 за
непродаваемую, ×0.5 за дубликат. Защищённые (по рейтингу/особые) не используются. Подбор —
имитация отжига; все ограничения (рейтинг по формуле EA, химия, редкость, лиги/нации/клубы) — жёсткие.

## Что НЕ проверено (калибровка на живом Web App)
Код в `src/userscript.js` использует внутренние API EA (`services.Club.search`, `services.SBC.submitChallenge`,
`SBCEligibilityKey`, `challenge.squad.setPlayers` и т.д.) по памяти о конвенциях Web App — из облачной
среды проверить нельзя. Первый запуск делайте с `submit:false` и смотрите консоль `[FC-SBC]`: если
встретится неизвестное требование — скрипт остановится и выведет его. Имена полей/ключей, скорее всего,
придётся поправить. Химия в ядре — верхняя оценка (игроки на родных позициях), финальную проверку делает EA.

## Риск
Автоматизация Web App запрещена условиями EA; аккаунты банили. Скрипт делает случайные паузы, но
безопасным это не делает. Используете на свой риск.
